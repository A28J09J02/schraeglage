# Schräglage

Motorrad-Touren planen – als Web-App direkt im Browser, auch auf dem iPhone („Zum Home-Bildschirm“).

- **Route planen:** kurvig oder schnell, Autobahn/Maut meiden, Zwischenziele per Suche oder Tipp auf die Karte
- **Rundtour:** Fahrzeit (1–6 h) und Richtung wählen, Stopps an Aussichtspunkten, Cafés, Burgen, Pässen, Biergärten, Seen
- **Tankplanung:** Reichweite aus dem eigenen Motorrad, Tankstopps an der Strecke
- **Wetter entlang der Route** inkl. gefühlter Temperatur im Fahrtwind
- **Export nach Google Maps** per Knopfdruck (lange Touren automatisch in Etappen), GPX-Export
- **Garage:** Motorrad wählen, Wartung (Kette, Öl, Reifen, Bremsflüssigkeit, TÜV) mit Restkilometern
- **Logbuch:** exportierte Touren bestätigen, Tachoabgleich, Monats-Challenge, Abzeichen
- **Teilen:** jede Tour als Link

Alle Daten bleiben lokal im Browser. Dienste: OpenStreetMap/CARTO (Karte), BRouter (Routing), Overpass (Highlights, Tankstellen), Photon (Suche), Open-Meteo (Wetter).
